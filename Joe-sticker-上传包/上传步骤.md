# Joe-s-sticker 上传步骤（5 步，照着点）

> 这个文件夹里三样东西：
> - `sticker-pack-studio/`　→ 第 3 步要拖进 GitHub 的文件夹
> - `sticker-pack-studio-v4.zip`　→ 第 4 步发 Release 用的附件
> - `README.md`　→ 第 5 步要粘进仓库的正文

---

## 第 1 步：填个人资料

github.com → 右上角头像 → **Settings** → 左边 **Public profile**

- **Name**：`是Joe啊`
- **Bio**：`文科生用 AI 上岸实录｜每期实测一个 AI 搞钱路子，赚到算数，踩坑也算数。小红书：是Joe啊`
- 拉到最底下 → 绿色 **Save changes**

## 第 2 步：删掉空的同名仓库

进 `sticker-pack-studio` 仓库 → 右上 **Settings** → 拉到最底部 **Danger Zone** → **Delete this repository** → 按提示输入仓库名确认

（不删的话两个仓库同名，流量会被拆散）

## 第 3 步：把 skill 文件夹传上去

1. 进 `Joe-s-sticker` 仓库
2. 先删错的文件：点 `SKILL.zip.md` → 右上垃圾桶图标 🗑 → Commit changes
3. 点 **Add file** → **Upload files**
4. 把桌面 `Joe-sticker-上传包` 里的 **`sticker-pack-studio` 文件夹**整个拖进网页
5. 拉到最下面点绿色 **Commit changes**

## 第 4 步：发 Release（别人下载就靠这里）

1. 仓库右侧栏 → **Releases** → **Create a new release**
2. **Choose a tag** 输入 `v4.0.0` → 点 "Create new tag"
3. Release title 填：`v4.0.0 去水印版`
4. 拉到 **Attach binaries** → 把 `sticker-pack-studio-v4.zip` 拖进去，等它上传完
5. 点 **Publish release**

## 第 5 步：写 README

1. 仓库首页点 `README.md` → 右上角铅笔 ✏️
2. 把里面原有内容**全删掉**，粘贴本文件夹 `README.md` 的全部内容
3. 拉到最下面 → **Commit changes** → 弹窗再点一次

---

## 做完自检（30 秒）

用浏览器**无痕窗口**（别人视角）打开你的仓库，确认三件事：

- [ ] 首页能看到 README，图片/文字显示正常
- [ ] 右侧能看到 Releases，点进去能下载那个 zip
- [ ] 仓库里能看到 `sticker-pack-studio` 文件夹，里面有 SKILL.md、references、scripts

三个都对 = 完成。
