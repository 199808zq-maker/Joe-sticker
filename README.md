Joe-sticker ｜表情包工坊
一张照片 → 一整套风格统一的微信表情包。
Turn one photo into a full, consistent WeChat sticker pack.
内置工具名：sticker-pack-studio（表情包工坊）
它解决什么问题
网上教 AI 做表情包的一堆，但真做起来会遇到三个坑：
1. 崩脸——八张图八个画风，同一个角色越长越不像
2. 成套难——单张好看，放在一起不像一套
3. 用不上——尺寸不对、带水印、微信里加不进去
这套工作流就是拿这三个坑一条条填出来的。
它能干嘛
- 锁定形象：先从照片里提取特征写成固定提示词 + 每次生成都带参考图，整套图同一个角色，不崩脸不换衣服
- 16 个场景主题：打工人 / 怼人斗图 / 红包 / 情侣 / 节日 / 考试 / 节气……对应微信表情开放平台的官方分类，填表直接照抄
- 打样确认：先出 1 张完整成品，你点头了才批量——避免做完 8 张才发现方向错了
- 文案逐张可改：文字风格 4 种预设，字体/颜色/描边全可控
- 自动去水印：清掉左下角「AI生成」标记
- 一键导出微信规格：240×240、保留透明通道、按序号命名
三种用法（按你的工具水平选）
用法一：不装任何东西，复制提示词（最简单）
把下面这段粘到任何支持画图的 AI 里，换成你自己的描述：
画一张 Q版卡通贴纸，主体是【一只橘猫 / 我自己：长直黑发、圆脸、大耳环】，
大头比例（头身比约1:1），巨大闪亮的眼睛，粗白色描边，纯米色背景。
动作：双手叉腰大笑。
风格：贴纸风，线条干净，高饱和，可爱不做作。
要做一整套，就把「动作」那一行换成 8 个不同动作，然后每次生成都带上第一张满意的图作为参考图——这一步是关键，不带参考图必然崩脸。
用法二：装进 AI agent（完整流程，推荐）
把你的 agent 装上这个 skill，发一张照片说一句「做一套打工人主题的表情包」，它会走完整条链路：锁形象 → 选场景 → 打样 → 批量 → 去水印 → 导出。
用法三：直接拿成品
仓库 Releases 里会放做好的成品表情包，下载后发到微信「文件传输助手」→ 长按图片 → 添加为表情，就能用。
怎么装（用法二）
1. 在右侧 Releases 下载 sticker-pack-studio-v4.zip，解压
2. 把解压出来的 sticker-pack-studio 整个文件夹，放进你的 agent 的 skills 目录
  - WorkBuddy：~/.workbuddy/skills/
  - Claude Code：~/.claude/skills/
3. 重启 agent，问它一句「你会做什么」——能答出「照片→选场景→打样→批量→去水印→导出240×240」就装对了
装不上就把 .zip 直接解压给 agent 读整个文件夹，效果一样。
依赖
- Python 3
- Pillow（pip install pillow）——两个后处理脚本需要
