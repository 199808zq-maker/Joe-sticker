# Sticker Pack Studio 表情包工坊

把一张照片变成一整套风格统一的表情包。核心心法：**先锁形象，打样一张，确认后再批量**。

## 工作流程

### 第1步：收集输入

向用户确认五样东西：
1. **主体照片**：本人/宠物/玩偶的清晰照片（用作生成参考图）
2. **画风**：给可点菜单，不要开放式提问：
   - Q版二次元贴纸风（粗白描边、大高光眼睛、腮红）——默认推荐，记忆点最强
   - 扁平插画风 / 像素风 / 豆豆眼极简风 / 其他用户自述风格
3. **场景主题**：读 `references/scene-library.md`，把场景菜单给用户选（默认16个场景对应微信表情平台分类，如打工人、怼人斗图、红包、情侣、节日等）。用户选定后，该场景的8个表情条目+默认文案就确定了
4. **服装指定（可选）**：用户可以提供服装参考图（如一件卫衣的照片）或口述描述（语音输入转文字亦可）。提供时形象段必须使用该服装，并将服装参考图一并作为生成参考图传入；未提供时给主体配一套默认服装并写入形象段。无论是哪种，**整套图服装锁死，不许中途换**
5. **文字**：确认每张图的文案（用场景默认文案或用户逐张改），以及文字风格（见第5步）

### 第2步：锁定形象段（最重要的一步）

从照片中提取主体的稳定视觉特征，写成一段**固定不变的"形象段"提示词**。必须包含：

- 主体类型与构图（如"Q版卡通女孩全身像，大头比例头身比约1:1"）
- 毛发/发型的颜色与形态（**给出hex色值**）
- 标志性配件（没有就写"无配饰"）
- 五官风格
- 服装及hex色值：**用户指定了服装就用用户的**（参考图或口述，采样/估算其hex色值写入）；未指定才用默认搭配。宠物默认不穿衣服，用户给宠物指定了服装则同样锁死
- 画风与描边（如"贴纸风格粗白色描边"）
- 背景（统一纯色底，整套一致；若需透明底贴纸则统一透明）

形象段给用户确认后，**整套图期间一个字都不许改**。每次生成必须把主体照片或已确认的基准图作为参考图一起传入——只靠文字描述必然漂移。

### 第3步：打样（pilot），先出一张

从选定场景中挑第1个条目，生成**一张完整成品**（含文案文字），交给用户确认三件事：
1. 形象像不像、画风对不对
2. 文案内容和文字风格行不行
3. 构图给文字留的位置够不够

用户提修改意见就调，直到这张打样通过。**打样没通过之前，禁止批量生成。**

### 第4步：批量生成姿势集

打样通过后，按场景的8个条目逐张生成。每张提示词 = 形象段原文 + 动作段（动作段来自 `references/pose-library.md` 或场景库自带条目）。

### 第5步：配文字（两种路线，优先B）

- **路线A（生成时带字）**：提示词里写"图上方带文字'XXX'，手写圆润字体，白色描边"。快，但AI写中文字容易出错
- **路线B（后期叠字，推荐）**：图生成时不带字，用脚本统一叠字，字体、颜色、描边、位置全部可控：
  ```bash
  python3 scripts/add_text.py 输入图.png 输出图.png --text "文案" --position top
  ```
  参数：`--text` 文案（空格分两行）；`--pos top|bottom`；`--size` 字号；`--color` 字色hex（默认白字深棕描边，贴纸风）

文字风格菜单（给用户选）：
1. 白字+深棕描边（默认，最百搭）2. 黑字无描边（性冷淡）3. 主色描边（取形象段主色做描边，整体感最强）4. 用户自定义

### 第6步：一致性自检（逐张过）

对照四条规则，任一不过就重生成：
1. 主色不飘（对照形象段hex）2. 标志特征在位 3. 无形象段以外的服装/元素变体 4. 与基准图是同一主体

### 第7步：去水印（导出前必做）

出图服务会自动在左下角压一个「AI生成」水印，这不是本 skill 加的，只能后期处理。批量清掉：

```bash
python3 scripts/remove_watermark.py <图片目录> --outdir <输出目录>
```

- 默认处理左下角区域；水印压到头发等复杂位置时用 `--rect X,Y,W,H` 手动框
- 背景是纯色的：自动采样周边背景色填补，边缘做了羽化，看不出补丁
- 背景是透明的：直接把该区域透明度清零，导出后是干净透明底
- 单张图：`python3 scripts/remove_watermark.py 原图.png 干净图.png`

去完水印**先抽一张放大看四角**，确认没有残留笔画或色块，再进导出。

### 第8步：导出微信规格

```bash
python3 scripts/export_wechat.py <输入目录> <输出目录>
```

自动等比缩放至240×240（长边顶满）、保留透明通道、按 `表情01.png` 序号命名。GIF动图保持240×240且单张≤500KB。上架缩略图加 `--size 120`。

### 第9步：交付与使用说明

交付导出目录，并告诉用户导入方法：
- 自用：手机微信 → 文件传输助手发送图片 → 长按 →「添加为表情」
- 上架赚钱：读 `references/wechat-platform.md`，含平台规格、主题/风格标签对应关系（场景库场景与平台标签一一对应，填表时直接照抄）、审核流程
