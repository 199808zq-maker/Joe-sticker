# 场景库 scene-library

16 个场景，对应微信表情开放平台主题分类。用户选定一个场景后，该场景的 8 个表情条目 + 默认文案即确定。
每个条目 = 动作段（接在形象段后面的动作/表情描述）+ 默认文案（用户可逐张改）。

平台标签对照见 `wechat-platform.md`。
