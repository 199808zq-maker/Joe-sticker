# 微信表情开放平台上架指南 wechat-platform

平台地址：sticker.weixin.qq.com（电脑端操作，微信扫码注册，个人主体 + 实名认证）

## 素材规格清单

| 素材 | 规格 | 格式 | 说明 |
|---|---|---|---|
| 表情主图 | 240×240 | PNG（透明）/GIF | 一套 8/16/24 张；GIF 单张 ≤500KB |
| 缩略图 | 120×120 | PNG（透明） | 与主图一一对应，`export_wechat.py --size 120` 生成 |
| 聊天面板图标 | 50×50 | PNG | 选一张最有辨识度的裁切 |
| 表情封面图 | 240×240 | PNG | 不得含文字 |
| 详情页横幅 | 750×400 | PNG/JPG | 展示形象，不得含二维码 |
| 赞赏引导图 | 750×560 | PNG/GIF | 开通赞赏时需要 |
| 赞赏致谢图 | 750×750 | PNG/GIF | 开通赞赏时需要 |

## 上传流程

1. 注册艺术家账号（个人 + 实名，1-2 个工作日审核）
2. 创建表情专辑：
   - 名称 ≤8 个字（不得含人名、IP 名、热点词）
   - 介绍 ≤80 字，**需注明「本作品由 AI 辅助生成」**（平台 AI 内容规范要求）
   - 版权名称填自己的名字或艺名
3. 类型选「卡通表情/其他」，主题和风格标签按下方对照表勾选
4. 上传全部素材，**勾选「接受赞赏」**，提交审核（通常 1-5 个工作日）
5. 审核通过后**手动点「上架」**（审核通过 ≠ 自动上架）
6. 赞赏功能：上架后在后台申请开通，需绑定银行卡

## 审核 8 大拒因（避坑清单）

1. 名人/影视/动漫 IP 形象（直接拒，绝不碰）
2. 整套风格不统一（形象段锁死 + 垫图生成可预防）
3. 文案含「官方/正版/认证」等背书词
4. 图片带二维码/水印/网址
5. 任意两张含义重复（文案清单阶段先查重）
6. 画质问题：锯齿/白边/透明通道错误
7. 专辑名称蹭人名、热点
8. 敏感题材（政治、血腥、性暗示等）

## 动态表情补充

- GIF 需 240×240、≤500KB、循环流畅
- 动态制作属于进阶流程：建议先用静态版跑通上架，再把高使用率的几张做成动态
- 可用帧动画方式生成（同一形象连续 2-4 帧动作），导出时保持帧率 ≤12fps 控制体积
